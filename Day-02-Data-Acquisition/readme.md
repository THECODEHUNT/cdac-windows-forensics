# Day 02 - Data Acquisition

## Overview

This session focused on Digital Evidence Acquisition and Forensic Imaging.

The objective of data acquisition is to collect digital evidence while maintaining integrity, authenticity, and legal admissibility.

---

## Topics Covered

- Data Acquisition Fundamentals
- Order of Volatility (RFC 3227)
- Physical Acquisition
- Logical Acquisition
- Live Acquisition
- Remote Acquisition
- Chain of Custody
- Write Blocking
- Forensic Image Formats
- Hash Verification
- Evidence Validation

## Important Concepts

### Order of Volatility

1. CPU Registers & Cache
2. RAM
3. Network Connections
4. Running Processes
5. Disk Storage
6. Remote Logs & Backups

### Evidence Validation

Hash algorithms used:

- MD5
- SHA1
- SHA256

Hash verification must be performed:

- Before acquisition
- During acquisition
- After acquisition
- Before analysis

## Key Learning Outcome

Understanding how forensic images are acquired while preserving evidence integrity and maintaining chain of custody.
